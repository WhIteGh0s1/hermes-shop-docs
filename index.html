Hermes Shop API

Подключите каталог Hermes Shop к своему сайту, боту или магазину: получайте товары и цены, покупайте с баланса и сразу получайте товар — без ручной работы.

Что можно делать через API:

  • получать актуальный каталог — названия, цены в рублях, наличие;
  • покупать товары с вашего баланса в боте и сразу получать данные товара в ответе;
  • оформлять предзаказы на товары, которых нет в наличии;
  • смотреть баланс и историю заказов.

Базовый адрес: https://АДРЕС-API · Формат: JSON · Кодировка: UTF-8 · Валюта: рубли

Быстрый старт

  1. Выпустите ключ. Откройте бота → Профиль → API-ключ → Выпустить ключ. Ключ начинается с hs_ и показывается один раз — сразу сохраните его.
  2. Пополните баланс в боте: Профиль → Пополнить баланс. Покупки через API списываются с этого баланса.
  3. Сделайте первый запрос — получите список товаров:
curl https://АДРЕС-API/api/v1/products \
  -H "X-API-Key: hs_ВАШ_КЛЮЧ"

Нашли нужный товар — купите его одним запросом (см. Покупка). Товар придёт прямо в ответе, а копия — сообщением в бот.

Авторизация

Каждый запрос к /api/v1/… должен содержать заголовок с ключом:

X-API-Key: hs_ВАШ_КЛЮЧ
  • Ключ привязан к вашему аккаунту в боте: покупки идут с вашего баланса и видны в «Моих покупках».
  • Храните ключ только на сервере. Не вставляйте его в код сайта, который видят посетители, и в мобильные приложения.
  • Если ключ утёк — нажмите в боте Перевыпустить ключ. Старый ключ перестанет работать сразу.

Формат ответов

Все ответы — JSON. Успешный ответ содержит "ok": true, ошибка — "ok": false и объект error:

{
  "ok": false,
  "error": {
    "code": "insufficient_balance",
    "message": "Не хватает средств: нужно 625.0 ₽, на балансе 100.0 ₽"
  }
}

Проверяйте поле error.code — оно не меняется. Текст message — для людей и может уточняться. Суммы — числа в рублях с копейками (625.0), даты — ISO 8601 в UTC.

Список товаров

GET/api/v1/products

Все товары, которые сейчас продаются. Цены и наличие обновляются автоматически каждые 5 минут — не храните их у себя надолго, запрашивайте перед показом покупателю.

curl https://АДРЕС-API/api/v1/products -H "X-API-Key: hs_ВАШ_КЛЮЧ"
import requests

API = "https://АДРЕС-API/api/v1"
HEADERS = {"X-API-Key": "hs_ВАШ_КЛЮЧ"}

data = requests.get(f"{API}/products", headers=HEADERS, timeout=30).json()
for p in data["products"]:
    print(p["id"], p["name"], p["price"], "₽", "в наличии:", p["stock"])
const API = "https://АДРЕС-API/api/v1";
const headers = { "X-API-Key": "hs_ВАШ_КЛЮЧ" };

const data = await fetch(`${API}/products`, { headers }).then(r => r.json());
for (const p of data.products) console.log(p.id, p.name, p.price, "₽", p.stock);

Баланс

GET/api/v1/balance
curl https://АДРЕС-API/api/v1/balance -H "X-API-Key: hs_ВАШ_КЛЮЧ"
{ "ok": true, "user_id": 8115200073, "balance": 1500.0, "currency": "RUB" }

Пополнение — только в боте. Проверяйте баланс перед крупными покупками, чтобы не получить ошибку insufficient_balance.

Покупка

POST/api/v1/orders

Списывает стоимость с баланса и сразу выдаёт товар. Запрос может занять до нескольких секунд — бот покупает товар у поставщика. Ставьте таймаут не меньше 60 секунд.

Если поставщик не смог выдать товар, деньги автоматически возвращаются на баланс, заказ получает статус refunded, а ответ приходит с "ok": false и кодом not_delivered.

Заказ по id

GET/api/v1/orders/{id}
curl https://АДРЕС-API/api/v1/orders/1057 -H "X-API-Key: hs_ВАШ_КЛЮЧ"

Возвращает {"ok": true, "order": {…}} в том же формате, что и покупка. Используйте, чтобы проверить предзаказ или заказ на проверке.

История заказов

GET/api/v1/orders?limit=50

Последние заказы, новые сверху. limit — от 1 до 200, по умолчанию 50. Сюда попадают заказы и из API, и из бота.

{ "ok": true, "count": 2, "orders": [ { "id": 1057, "status": "delivered", … }, … ] }

Данные для активации

Некоторые товары активируются на данных покупателя — например, подписка на его email или накрутка на его профиль. У таких товаров в каталоге поле activation не null, и при покупке нужно передать activation_data:

activationЧто передатьПример
emailEmail покупателяuser@gmail.com
usernameИмя аккаунта (для соцсетей)@my_profile
linkСсылка на публикацию или профильhttps://instagram.com/p/xyz
countryСтрана аккаунтаUSA
{"product_id": 77, "quantity": 1, "activation_data": "user@gmail.com", "external_id": "my-order-1002"}

Без activation_data такой заказ вернёт ошибку activation_required, деньги не спишутся.

Предзаказ

Если stock равен 0 (или меньше нужного количества), товар можно купить заранее: передайте "preorder": true. Деньги списываются сразу, заказ получает статус paid. Как только товар поступит, он будет выдан в первую очередь — раньше обычных покупок, в порядке оформления предзаказов. Статус сменится на delivered, а данные появятся в items — проверяйте через GET /orders/{id}.

{"product_id": 42, "quantity": 3, "preorder": true, "external_id": "pre-2001"}

Защита от повторов

Сеть иногда обрывается: запрос дошёл, а ответ — нет. Чтобы при повторе не купить товар дважды, передавайте external_id — уникальный номер заказа в вашей системе.

  • Первый запрос с external_id создаёт заказ.
  • Повтор с тем же external_id ничего не списывает и возвращает тот же заказ с полем "duplicate": true.
Правило простое: получили таймаут или ошибку сети — повторите запрос с тем же external_id. Новый external_id — только для нового заказа.

Лимиты

  • До 10 запросов в секунду на один ключ. При превышении — ошибка 429, повторите через секунду.
  • Каталог обновляется раз в 5 минут — чаще запрашивать его не нужно. Кэшируйте список товаров у себя на 1–5 минут.
  • Таймаут для покупки — не меньше 60 секунд.

Пример интеграции

Типичный сценарий: у вас свой бот или сайт, и вы перепродаёте товары Hermes Shop.

  1. Раз в несколько минут загружайте /products и показывайте покупателям товары со своей ценой.
  2. Покупатель оплатил у вас — вызовите POST /orders с external_id = номер заказа в вашей системе.
  3. Если статус delivered — отдайте покупателю строки из items.
  4. Если paid (предзаказ) или review — сохраните order.id и проверяйте его, пока не станет delivered.
  5. Если ошибка сети — повторите тот же запрос с тем же external_id.
import time
import requests

API = "https://АДРЕС-API/api/v1"
HEADERS = {"X-API-Key": "hs_ВАШ_КЛЮЧ"}


def buy(product_id: int, qty: int, my_order_id: str, activation: str | None = None) -> list[str]:
    """Купить товар и дождаться выдачи. Возвращает строки товара."""
    body = {"product_id": product_id, "quantity": qty, "external_id": my_order_id}
    if activation:
        body["activation_data"] = activation

    for attempt in range(3):  # повтор при сбое сети — с тем же external_id, без двойного списания
        try:
            data = requests.post(f"{API}/orders", headers=HEADERS, json=body, timeout=90).json()
            break
        except requests.RequestException:
            time.sleep(2 * (attempt + 1))
    else:
        raise RuntimeError("API недоступен")

    if not data["ok"]:
        raise RuntimeError(data["error"]["message"])

    order = data["order"]
    while order["status"] in ("paid", "review"):  # предзаказ или проверка — ждём
        time.sleep(60)
        order = requests.get(f"{API}/orders/{order['id']}", headers=HEADERS, timeout=30).json()["order"]

    if order["status"] != "delivered":
        raise RuntimeError("Заказ не выдан, деньги вернулись на баланс")
    return order["items"]

Частые вопросы

Цены в API такие же, как в боте?

Да, это те же цены, что видят покупатели в боте, в рублях.

Где посмотреть заказы, сделанные через API?

В боте: Профиль → Мои покупки. Там же — данные выданных товаров. Бот также присылает сообщение о каждой выдаче.

Можно ли несколько ключей?

Один аккаунт — один ключ. Перевыпуск отключает старый ключ.

Товар выдан, но не работает

Напишите в поддержку через бота (Профиль → Поддержка) и укажите номер заказа id.

Как проверить, что сервис доступен?

GET https://АДРЕС-API/health — без ключа, отвечает {"ok": true}.
